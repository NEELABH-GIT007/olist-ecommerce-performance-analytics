# SQL

This directory will contain portfolio-ready SQL from the project.

Planned structure:

- cleaning/
- analytical_models/
- business_analysis/
- reporting_layer/

SQL will be promoted here only after it has been reviewed for:

- clear analytical purpose
- correct grain
- correct join behavior
- efficient aggregation
- readable naming
- appropriate validation and reconciliation

The goal is not to publish every development query, but to show production-minded analytical SQL.
