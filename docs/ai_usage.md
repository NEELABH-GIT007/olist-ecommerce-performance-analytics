# Use of Generative AI

Generative AI was used during this project as a **learning, review and productivity assistant**.

Typical uses included:
- explaining technical concepts
- discussing alternative SQL and modeling approaches
- debugging support
- reviewing documentation structure
- challenging assumptions
- preparing interview and communication material

AI output was not treated as authoritative.

Before accepting an analytical result, the project workflow required independent validation against the underlying data, including:
- grain checks
- relationship checks
- metric reconciliation
- transformation validation
- Tableau-to-SQL reconciliation
- business-logic review
- distinction between association and causation

This disclosure is included deliberately to make the project workflow transparent.
